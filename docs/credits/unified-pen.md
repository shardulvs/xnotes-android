# Unified pen interface attribution

The unified pen launcher retains the radial hold-and-drag selection gesture developed for XNotes PR #429.

Its stroke icon presentation and inline pen-family selection within the existing tool settings dialog are adapted from the implementation in [N-Notes](https://github.com/NeDDy3z/n-notes), maintained by [NeDDy3z](https://github.com/NeDDy3z). Thanks to the maintainer for explicitly allowing reuse and collaboration.
